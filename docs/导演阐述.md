# 《破立并举 统筹兼顾》研读微视频 · 导演阐述

## 一、立意

《论十大关系》不是十条政策清单，而是一套处理矛盾的方法。全片要让观众带走的只有一句话：

> **看问题“总是两点而不是一点”；处理矛盾，要有主有次，又不只顾一头。**

切入点选文中最反直觉、也最能体现辩证法的修辞：讲话三次追问“真想还是假想”。

- 真想要重工业 → 多发展农业、轻工业；
- 真想要内地工业 → 多利用沿海老底子；
- 真想要原子弹 → 降低军政费用，多搞经济建设。

要抓住这一头，先得照顾好那一头。这就是“统筹兼顾”，也是报告标题里“破立并举”的落点：
破对苏联模式的迷信、破“只顾一头”的片面；立从中国实际出发的建设道路与方法。

深度来源（必须在片中体现，而不是只复述原文）：

1. **方法论主线**：十种关系都是矛盾 → 两点论 → 统筹兼顾不是平均主义，而是“有重点的兼顾”（中心意象：杆秤）。
2. **以苏为鉴**：每一板块都给出苏联的反例（片面重工业、挖农民、把地方卡死、一党、照抄）。
3. **实事求是的纠错**：1954 年多购七十亿斤粮食 → 1955 年少购、“三定”，“这个教训，全党必须记住”。
4. **报告的原创结构**：十位组员各领一条精读，打破原顺序重组为四大板块。
5. **研读追问**：报告提出的四个开放问题以“页边红笔批注”形式出现，体现“学思悟”而不是背诵。
6. **历史诚实**：引用讲话自己的话“也要准备两种可能性”，承认探索之路并不平坦。
7. **时代坐标**：1956—2026，整整七十年；四组关系延续为新型工业化与乡村振兴、区域协调发展、军民融合发展、共同富裕。

## 二、视觉体系：「铅字与朱砂」

整片的视觉母题是**研读本身**：一本 1976 年人民出版社单行本、一支红铅笔、一页页被划线和批注的原文。

| 要素 | 规范 |
|---|---|
| 底色 | 旧纸 `#EDE5D4`（主）、`#E4D9C3`（暗部）；纸纹、纤维、轻微暗角 |
| 墨色 | 铅字黑 `#1C1A17`；次级灰 `#6B655B` |
| 朱砂 | `#B5302A`（1976 年封面红），只用于强调、划线、批注、数据中的“重点” |
| 辅色 | 旧铜 `#8A6A3B`（极少量，用于秤星、金属反光） |
| 字体 | 标题：思源宋体 Heavy；引文：华文宋体/Noto Serif SC；批注：华文楷体；数字：Noto Serif SC |
| 原文 | 一律使用 1976 年版真实扫描页，红铅笔划线动画，不重新排版冒充原件 |
| 图解 | 细墨线 + 实心圆节点；“一对关系” = 两端节点 + 一条张力线；重点一端用朱砂 |
| 插图 | 新兴木刻风格（黑白阳刻、刀痕、无灰阶），后期二值化 + 纸纹，杜绝 AI 光滑渐变感 |
| 3D | 只用在三个有意义的物件上：铅字、杆秤、1976 年小册子；均为暖色自然光、浅景深、静物摄影质感 |
| 运动 | 慢、稳、克制。缓入缓出（bezier 0.16,1,0.3,1），没有弹跳、没有旋转飞入、没有粒子特效 |
| 字幕 | 底部居中，Noto Serif SC 44px，墨色字 + 纸色描边阴影；原文引用句不加书名号以外的修饰 |

禁止：AI 生成的领袖形象；地图（避免国界错误，空间关系用文字与比例表达）；霓虹、科技蓝、光效粒子；无意义的 3D 漂浮文字。
