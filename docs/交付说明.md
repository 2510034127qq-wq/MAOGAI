# 交付说明

## 成片
| 文件 | 说明 |
|---|---|
| `video/out/论十大关系_研读_字幕版.mp4` | 1920×1080 / 30fps，烧录字幕，无声（等待配音） |
| `video/out/论十大关系_研读_无字幕版.mp4` | 同上，不带字幕，便于后期在剪辑软件里自己加字幕 |
| `docs/字幕.srt` | 与成片时间轴一致的字幕文件 |
| `docs/配音稿.md` | 每句的编号、时间码、语气提示和对应画面 |
| `docs/导演阐述.md` | 立意、视觉体系、结构、分工、审核标准 |

## 配音（两种做法，任选其一）

**做法 A：按时间码配（简单）**
打开 `docs/配音稿.md`，看着无声成片，按每句的时间码录。语速基准约每秒 4.7 字，原文引用放慢到约 4.1 字。

**做法 B：让画面跟着配音走（推荐，最精确）**
1. 每句单独录一条，文件名用配音稿里的句首编号，例如 `S0_01.wav`、`B1_07.wav`（wav/mp3/m4a/flac 都可以）。
2. 全部放进 `assets/vo/`。
3. 运行：
   ```
   python tools/fit_voice.py
   cd video
   npx remotion render Main "out/论十大关系_研读_字幕版.mp4"
   ```
   脚本会量出每条录音的真实长度，重新计算整片节拍、字幕与转场，并把配音混进成片。没录的句子保持原来的预估时长。

## 背景音乐建议
全片基调是“研读”而不是“宣传片”：建议一段很轻的钢琴或弦乐长音铺底（音量压在配音下 18–22dB），
板块转场（壹贰叁肆标题卡）处可加一声低沉的钢琴单音；1964 年那一镜可以短暂留白、只保留环境声。
避免激昂的进行曲和鼓点。

## 重新渲染与修改
- 改台词：编辑 `docs/script.json` → `python tools/timing.py` → 重新渲染。
- 预览：`cd video && npx remotion studio`（浏览器里逐场景查看）。
- 3D 镜头源文件在 `blender/` 各任务目录（`.blend` 与生成脚本），渲染帧在 `assets/renders/`，运行 `python tools/sync_assets.py` 后进入成片。
